Seizure Log

This log lists every recorded seizure entry. Update data/seizure-log.json to make changes.

Open Recoveries manager
How to add a new seizure log
  1. Open the Recoveries page and use Manage Recoveries to add or edit an entry.
  2. Click Generate code to create a JSON block, then paste it inside the entries array in data/seizure-log.json.
  3. Save the file and refresh this page. Each entry will appear between **** START **** and **** END **** for easy scanning.

The Recoveries dashboard and this log both read from the same JSON file, so every update stays in sync.
